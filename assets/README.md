# 프로젝트 이미지

- `hero.svg` / `hero.png`: 카메라·LiDAR 융합부터 차량 제어까지의 프로젝트 대표 이미지
- `architecture.svg` / `architecture.png`: 본선 V7의 처리 구조도
- `bev-representation-comparison.png`: 대표점 축약과 차선 마스크 보존 방식의 BEV 비교 화면
- `path-label-editor.png`: 일반·지름길 경로를 수정하고 저장하는 라벨 보정 도구 화면

대표 이미지와 구조도는 포트폴리오용 벡터 그래픽이며, BEV 비교 화면과 라벨 보정 도구 화면은 실제 개발 과정에서 사용한 자료입니다.

SVG는 수정 가능한 원본이고 PNG는 GitHub 표시 호환성을 위한 이미지입니다. 폰트는 Malgun Gothic / Segoe UI / Arial 계열을 사용합니다.
