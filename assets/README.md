# Visual assets

- `hero.svg` / `hero.png`: 프로젝트 소개용 개념 이미지
- `architecture.svg` / `architecture.png`: 코드에서 확인한 처리 구조
- `bev-representation-comparison.png`: 프로젝트 개발 기록에 수록한 BEV 표현 비교 화면
- `path-label-editor.png`: 프로젝트 개발 기록에 수록한 경로 라벨 보정 도구 화면

대표 이미지와 구조도는 이 포트폴리오를 위해 제작한 벡터 그래픽입니다. 그 안의 경로 모양, 격자 활성 패턴, 노드 배치는 설명용이며 실제 주행 기록·실험 결과가 아닙니다.

BEV 비교 화면과 라벨 보정 도구 화면은 프로젝트 개발 기록의 이미지를 수정 없이 사용했습니다. 비교 화면의 셀 수는 해당 프레임의 값이고, 라벨 보정 도구의 샘플 수는 당시 작업본의 값입니다. 인물이 포함된 카메라 사진과 비공개 문서 전체는 포함하지 않았습니다.

SVG는 수정 가능한 원본이고 PNG는 GitHub 표시 호환성을 위한 이미지입니다. 폰트는 Malgun Gothic / Segoe UI / Arial 계열을 사용합니다.
