# 구현 범위와 실행 참고

[프로젝트 소개로 돌아가기](../README.md)

이 문서는 보관 저장소의 `8036461664402a54821b0665a4434e961f9a2e76` 커밋과 본선 V7 설정을 기준으로 합니다. 포트폴리오 제작 과정에서 ROS 빌드·모델 추론·차량 주행은 수행하지 않았습니다.

## 예선과 본선의 차이

예선은 차선·라바콘에 대한 2차 곡선 피팅과 상태 머신 중심입니다. 본선 V7은 카메라의 분할 결과와 LiDAR를 BEV로 정리하고 주행 모드별 CNN으로 경로를 생성합니다. 두 단계의 자료를 같은 실행 버전으로 혼합하지 않습니다.

본선 V7의 최종 장애물 회피 설정은 `hardcoded_all`입니다. 네 가지 CNN 모델이 코드에 존재하지만 고정 조향 블록이 활성화되는 회피 구간이 있으므로, 모든 상황에서 CNN 출력만으로 조향한다고 설명하지 않습니다.

## 실행 환경

| 항목 | 원본 자료에 기록된 조건 |
|---|---|
| 기본 환경 | Ubuntu · ROS 2 Humble |
| 모델 | PyTorch, Ultralytics, OpenVINO 관련 의존성 |
| 차량 연동 | ROS1 모터 브리지, VESC·센서 드라이버, 조향 보정 및 차량 외부 스크립트 |
| 경로 | 설정에 개발 차량의 모델·설치 절대 경로 포함 |
| 패키지 의존 | `track_drive_cnn_gpt`에서 `track_drive`의 `CarInterface`와 설정을 사용 |
| 모델 보관 | 6개 PT 모델과 OpenVINO 변환 파일의 체크섬 기록 |

복원은 [원본 V7 안내](https://github.com/jounget5411-lab/2026-Legend-KHUSLA/blob/8036461664402a54821b0665a4434e961f9a2e76/본선_최종_V7_안내.md)의 환경·모델 배치 절차를 기준으로 진행합니다. 현재 포트폴리오는 독립 실행용 코드 배포가 아닌 설명 문서입니다.

## 확인해야 할 실행 동작

- BEV·LiDAR의 시간 차이와 경로 형식을 검사하는 코드가 있습니다. 제어 노드는 새 경로를 거절하거나 받지 못하면 이전 유효 경로·조향을 유지할 수 있습니다. 경로 유실이 자동 정지를 뜻하지는 않습니다.
- 최종 설정의 `race_finish_enabled`는 `false`입니다. 자동 랩 종료를 현재 활성 기능으로 설명하지 않습니다.
- `speed_cmd`는 차량 명령값입니다. 별도 보정 자료 없이 km/h로 환산하지 않습니다.
- 20 Hz는 제어 타이머 설정이며 실측 추론 FPS가 아닙니다. BEV 크기와 셀 해상도 역시 구현 설정입니다.
- 테스트 파일과 모델 체크섬 기록은 저장소에 포함되어 있습니다. 이번 문서 작성 과정에서 테스트 재실행이나 전체 모델 파일의 체크섬 재계산은 하지 않았습니다.

## 그림과 성과 자료

대표 이미지와 구조도는 코드에 근거해 새로 만든 개념 그림입니다. 실차 사진·대회 영상·경로 측정 결과가 아닙니다. 예선·본선 진행 표기는 프로젝트 자료를 따르며, 완주 시간·순위·인식 정확도·개선율은 검증 자료 없이 추가하지 않았습니다.

[주장별 소스 근거](source-guide.md)에서 각 설명에 연결된 파일을 확인할 수 있습니다.
